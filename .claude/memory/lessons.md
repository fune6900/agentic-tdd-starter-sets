# 教訓ログ（Lessons）

ループが学習するための外部メモリ。セッションを跨いで引き継がれる唯一の資産。

**書き込みは `/loop-retro` 経由。** 手書きで雑に追記しない。
書き方と運用ルールは `@.claude/memory/README.md` を参照。

---

## 使い方（このテンプレを導入したプロジェクトでの初手）

1. 最初の Issue が完了したら `/loop-retro` を実行し、この下に教訓を積む
2. 立案のメイド（Planner）は分解前に必ずこのファイル全体を読む
3. 同じ事象が再発したら、新規追加ではなく既存項目に日付を追記する
